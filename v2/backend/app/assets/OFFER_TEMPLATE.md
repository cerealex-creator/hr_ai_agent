# Шаблон оффера (Word)

## Куда положить файл

**Через интерфейс (рекомендуется):** раздел «Оффер» в карточке кандидата → блок «Шаблон Word» → «Загрузить .docx». Файл сохраняется в `data/offer_template.docx`.

**По умолчанию (встроенный):**

```
v2/backend/app/assets/offer_template.docx
```

**Или** свой путь в `v2/.env` (перекрывает загрузку через UI):

```
OFFER_TEMPLATE_PATH=/полный/путь/к/вашему/offer.docx
```

Раздел **Оффер** в карточке кандидата сохраняет черновик полей и подставляет их в шаблон при «Скачать Word».

## Плейсхолдеры

| Метка | Смысл |
|-------|--------|
| `{{greeting}}` | Уважаемая / Уважаемый |
| `{{name_patronymic}}` | Имя и отчество |
| `{{full_name}}` | ФИО полностью (подпись) |
| `{{company}}` | Компания |
| `{{position}}` | Должность |
| `{{office_address}}` | Адрес офиса |
| `{{work_schedule}}` | Режим рабочего дня |
| `{{start_date}}` | Дата выхода |
| `{{probation_months}}` | Испытательный срок (в UI — только число: `3` → «3 месяца») |
| `{{salary_probation_line}}` | ЗП на ИС (оклад ± премия) |
| `{{salary_after_line}}` | ЗП после ИС (оклад ± премия) |
| `{{duties}}` | Обязанности (несколько строк → несколько абзацев) |
| `{{manager_name}}` | ФИО руководителя |

Логотип компании (если загружен в разделе Оффер) вставляется в **верхний колонтитул**.

## Замечания

- Плейсхолдер держите целиком в одном фрагменте текста Word.
- Структуру письма меняйте в `.docx`; цифры и ФИО — в разделе «Оффер» в UI.
