## Как пользоваться

1. Идти **строго по порядку сверху вниз** — разделы выстроены как рабочий день: вход → вакансия → кандидат → заказчик → аналитика → настройки.
2. В колонке **Статус** ставить одно из:
   - `ОК` — работает как ожидалось
   - `НЕ ОК` — не работает / работает не так
   - `?` — непонятно, нужен разбор
   - `—` — не проверял
   - `н/п` — не применимо (функция выключена на сервере)
3. Если `НЕ ОК` или `?` — в **Замечание** коротко: что нажал, что увидел. Если есть скриншот — положить рядом и указать имя файла.
4. Заполненный файл — см. раздел **«Куда положить заполненный чек-лист»** в конце.

## Что сейчас ВЫКЛЮЧЕНО на сервере (проверено 12.08.2026)

Это не баги — это отсутствие ключей/настроек. Проверять надо только то, что **интерфейс не ломается**, а выдаёт понятное сообщение.

| Интеграция | Состояние на сервере | Что это значит для теста |
|---|---|---|
| Telegram (бот, уведомления, карточки в чат) | выключен, токена нет | Кнопки отправки в чат должны давать понятную ошибку, а не «белый экран» |
| HH.ru (поиск резюме) | ключей нет | Вкладка «Поиск HH» скорее всего скрыта. Если видна — при поиске ожидаема ошибка |
| Яндекс.Диск (папки, inbox, синхронизация) | токена нет | Синхронизация и inbox работать не будут |
| Расшифровка видео (SpeechKit) | ключа нет | «Расшифровать и оценить» работать не будет |
| Zoom | не подключён | «Zoom (авто-генерация)» работать не будет |
| Google Calendar | не подключён | События в календарь создаваться не будут |
| Bitrix24 | выключен, вебхука нет | Отправка заказчику пойдёт только в клиентскую зону (веб) |
| **ИИ (RouterAI)** | **включён, ключ есть** | **Все ИИ-функции должны работать по-настоящему** |

Данные на сервере есть: 8 компаний, 5 вакансий, 55 кандидатов — тестировать можно на живых карточках.

> **Важно:** для теста лучше завести **отдельную тестовую вакансию** и в ней тестового кандидата, чтобы не портить рабочие данные. Удаление и смену этапов проверять только на них.
