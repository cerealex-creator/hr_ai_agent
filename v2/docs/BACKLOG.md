> Сделано → `.cursor/DEVLOG.md`.

## Git-ветка реализации

**Ветка:** `feature/kaskad-yakor-assistent-efir` (origin)

| Что | Куда |
|-----|------|
| Планы, бэклог, **вся реализация** по **КАСКАД**, **ЯКОРЬ**, **АССИСТЕНТ**, **ЭФИР** | эта ветка |
| План **СИСТЕМА** (СУП) | документ в `v2/docs/`; ветка реализации — решить при старте U1 (отдельная или эта же с префиксом `sistema:`) |
| Макеты, демо, текущий деплой, прочие фичи v2 | `feature/v2` |

**Порядок работы:**
1. Старт по кодовому слову — checkout `feature/kaskad-yakor-assistent-efir` (или короткая ветка от неё для отдельного PR).
2. Код, миграции, UI, правки планов — коммит **сюда**.
3. Готовая фаза → merge/cherry-pick в `feature/v2` → деплой.

Не смешивать реализацию этих четырёх инициатив с несвязанными изменениями на `feature/v2`.  
**СИСТЕМА** — отдельный SKU; не смешивать с КАСКАД/ЯКОРЬ в одном PR без явной команды.
