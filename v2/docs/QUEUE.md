# QUEUE — ближайшая очередь работ

> **Кодовое слово:** **`ОЧЕРЕДЬ`** — записать сюда / взять задачу отсюда / отметить статус.  
> Крупные задачи → [`BACKLOG.md`](BACKLOG.md).  
> Сделано → `.cursor/DEVLOG.md`.

## Правила

| Критерий | Сюда (QUEUE) |
|----------|--------------|
| В текущую архитектуру, без новой сущности (или минимальная) | ✅ |
| Оценка ≤3 дней | ✅ |
| Можно в одном PR с другими queue-задачами | ✅ |

**Приоритет:** P0 (срочно) → P1 → P2  
**Статусы:** `inbox` → `ready` → `in_progress` → `done`

**Шаблон записи:**
```markdown
### [Q-YYYY-MM-DD-NN] Название
- **Источник:** …
- **Суть:** …
- **Модуль:** …
- **Сложность:** S | M
- **Приоритет:** P0 | P1 | P2
- **Зависимости:** …
- **Статус:** inbox | ready | in_progress | done
- **Файлы (ожидаемые):** …
```
