# Telegram-клиентская зона (MVP)

## Что умеет

После отправки кандидата в чат (кнопка «Отправить в общий чат») под сообщением появляются кнопки:

- 🟢 Встреча
- 🟡 Подумать
- 🔴 Отказ
- 🟢 Оффер
- 💬 Комментарий

Нажатие сохраняется в `data/vacancies_db.json` — видно в HR-приложении и веб-зоне `/client`.

## Перед первой отправкой

1. **Полностью перезапустите Streamlit** (Ctrl+C в терминале, затем снова `streamlit run hri_full_v1.py`).
2. Запустите бота (см. ниже).
3. Отправьте кандидата заново — кнопки появляются только у **новых** сообщений.

После отправки в приложении должно быть: **«Кандидат отправлен в чат с кнопками статуса»** (зелёное).  
Если жёлтое предупреждение — напишите текст ошибки.

## Запуск бота (обязательно для кнопок)

В **отдельном** терминале (рядом со Streamlit):

```bash
cd /Users/aleksandr/Desktop/hr_ai_agent
source venv/bin/activate
python bot.py
```

Должно появиться: `запуск polling для @имя_бота` и `Команды бота зарегистрированы`.

После перезапуска в чате слева от поля ввода (кнопка **Меню** / ☰) появятся команды: в группе — `/candidates`, `/pending`; в личке — `/start`, `/menu`.

**`/candidates`** (или `/candidates Кладовщик`) — навигатор по карточкам кандидатов **конкретной вакансии** (по её id, с датами открытия/закрытия). Повторный «Кладовщик» в другом месяце — другая вакансия, без путаницы.

**Сводка по кандидатам** в чат приходит автоматически по **вторникам в 18:00** и **пятницам в 15:00** (МСК). Вручную — кнопка «📨 Статистика в чат» у вакансии в приложении. В карточке кандидата — «Напомнить о кандидате» / «Напомнить принять решение».

## Как пользоваться в чате

1. HR отправляет кандидата кнопкой в приложении.
2. Руководитель выбирает статус — карточка **обновляется**, в чат приходит **уведомление** (кто выбрал статус). Для **Отказ** и **Подумать** нужен комментарий; **Встреча** и **Оффер** — без комментария.
3. `/pending` в групповом чате — список кандидатов «ждут оценки»; при нескольких вакансиях в одном чате — выбор вакансии.
4. Бот присылает напоминания: за **1 час** до встречи; ежедневно о **просрочке оценки** (>суток без статуса); **один раз** о статусе «Подумать» >5 дней. Все — ответом на карточку кандидата.
5. **Сменить статус** — снова показываются кнопки статусов и «Отмена».
6. **Комментарий** — кнопка 💬 или ответ на карточку; отдельно от смены статуса.
7. **📅 Встреча** — выбор даты, времени и формата (офис / удалённо / оба).
8. **❌ Отменить встречу** — сбрасывает дату и время. Также при «Отказ» / «Подумать».
9. После назначения встречи — запрос подтверждения HR (`TELEGRAM_HR_CONFIRM_USERNAME` в `.env`).

> Удаление сообщения пользователя в группе работает, если бот — **администратор** чата.

## Требования

- В `.env` задан `TELEGRAM_BOT_TOKEN`
- Бот добавлен в групповой чат вакансии
- У вакансии указан Chat ID
