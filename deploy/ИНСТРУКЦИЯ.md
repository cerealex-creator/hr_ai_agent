# Вывод HR-приложения в интернет

Схема: **VPS в РФ (Timeweb) + Docker**.  
Вы и клиенты работаете с **одним сервером** — данные всегда актуальны.

---

## Ссылки после запуска

Замените `IP` на адрес вашего сервера (например `185.123.45.67`):

| Кому | Ссылка |
|------|--------|
| HR (вы) | `http://IP:8501/` |
| Руководитель компании | `http://IP:8501/master` |
| Руководитель отдела «Маркетинг» | `http://IP:8501/client?dept=Маркетинг` |
| Руководитель отдела «Продажи» | `http://IP:8501/client?dept=Продажи` |

Список отделов — в `data/departments.json`.

> **Важно:** ссылку `http://IP:8501/` (главная) **не отправляйте** клиентам — только `/master` и `/client?dept=...`.

## Итерация 1 — Заказ VPS на Timeweb

### 1.1. Регистрация

1. Откройте https://timeweb.cloud/
2. Нажмите **«Регистрация»** → введите email и пароль → подтвердите почту.

### 1.2. Создание сервера

1. В личном кабинете: **«Облачные серверы»** → **«Создать сервер»**.
2. Параметры:
   - **ОС:** Ubuntu 22.04 LTS
   - **Регион:** Москва или Санкт-Петербург
   - **Конфигурация:** минимум **2 CPU / 4 ГБ RAM / 40 ГБ SSD**  
     (меньше 4 ГБ RAM Whisper и ИИ могут тормозить или падать)
   - **Имя:** `hr-app` (любое)
3. **SSH-ключ** (рекомендуется):
   - На Mac откройте Терминал и выполните:
     ```bash
     ssh-keygen -t ed25519 -f ~/.ssh/timeweb_hr -N ""
     cat ~/.ssh/timeweb_hr.pub
     ```
   - Скопируйте вывод (начинается с `ssh-ed25519 ...`) и вставьте в поле SSH-ключа на Timeweb.
4. Нажмите **«Создать»** и дождитесь статуса **«Активен»** (2–5 минут).

### 1.3. Запишите данные доступа

В карточке сервера найдите:

- **IP-адрес** (например `185.123.45.67`)
- **Логин:** обычно `root`

### 1.4. Проверка входа с Mac

```bash
ssh -i ~/.ssh/timeweb_hr root@ВАШ_IP
```

Если ключа нет — Timeweb пришлёт пароль root на email.  
При первом входе введите `yes` на вопрос о fingerprint.

**Когда войдёте на сервер — напишите «Итерация 1 готова» и пришлите IP (пароль не присылайте).**

## Итерация 2 — Установка Docker на сервере

На сервере (после `ssh ...`):

```bash
apt-get update && apt-get install -y git rsync
```

Скопируйте проект с Mac (команда выполняется **на Mac**, в папке проекта):

```bash
cd /Users/aleksandr/Desktop/hr_ai_agent
chmod +x deploy/*.sh
./deploy/sync-to-server.sh root@ВАШ_IP
```

Вернитесь на сервер и установите Docker:

```bash
cd /opt/hr_ai_agent
chmod +x deploy/install-docker.sh
sudo bash deploy/install-docker.sh
```

**Проверка:** должны появиться версии `docker` и `docker compose`.

Напишите **«Итерация 2 готова»**.

## Итерация 3 — Секреты и данные

### 3.1. Файл `.env` на сервере

На Mac ваш `.env` уже есть локально. Скопируйте его на сервер:

```bash
scp -i ~/.ssh/timeweb_hr /Users/aleksandr/Desktop/hr_ai_agent/.env root@ВАШ_IP:/opt/hr_ai_agent/.env
```

(Если SSH-ключа нет — уберите `-i ~/.ssh/timeweb_hr`.)

### 3.2. Папка `data/`

Скрипт `sync-to-server.sh` уже копирует `data/` с кандидатами и вакансиями.

Проверка на сервере:

```bash
ls -la /opt/hr_ai_agent/data/
```

Должны быть файлы вроде `vacancies_db.json`, `departments.json`.

Напишите **«Итерация 3 готова»**.

## Итерация 4 — Запуск приложения

На сервере:

```bash
cd /opt/hr_ai_agent
docker compose up -d --build
```

Первый запуск **10–20 минут** (скачивается Python, Whisper, зависимости).

Статус:

```bash
docker compose ps
docker compose logs -f hr-app
```

Остановить просмотр логов: `Ctrl+C`.

### Открыть порт в Timeweb

1. Личный кабинет Timeweb → ваш сервер → **«Сеть»** / **«Firewall»**.
2. Разрешите входящий **TCP порт 8501** (источник: любой / 0.0.0.0/0).

### Проверка в браузере

- `http://ВАШ_IP:8501/master`
- `http://ВАШ_IP:8501/client?dept=Маркетинг`

Напишите **«Итерация 4 готова»** и что видите в браузере.

## Итерация 5 — Ссылки для руководителей

Составьте список (подставьте свой IP):

```
Мастер-зона (генеральный директор):
http://ВАШ_IP:8501/master

Маркетинг:
http://ВАШ_IP:8501/client?dept=Маркетинг

Продажи:
http://ВАШ_IP:8501/client?dept=Продажи
```

Название в `dept=` должно **точно совпадать** с полем `name` в `data/departments.json`.

## Полезные команды

| Действие | Команда (на сервере) |
|----------|----------------------|
| Перезапуск | `cd /opt/hr_ai_agent && docker compose restart` |
| Остановка | `docker compose down` |
| Логи | `docker compose logs -f hr-app` |
| Обновить код с Mac | `./deploy/sync-to-server.sh root@IP` затем `docker compose up -d --build` |

## Домен и HTTPS (позже)

Когда купите домен (например `hr.компания.ru`):

1. A-запись домена → IP сервера.
2. Поставить Caddy или nginx с Let's Encrypt.
3. Ссылки станут `https://hr.компания.ru/master` и т.д.

Без домена на старте работаем по `http://IP:8501/...` — этого достаточно для проверки.

## Безопасность

- Не публикуйте главную страницу `/` — только `/master` и `/client`.
- Файлы `.env` и `data/` не попадают в git.
- Позже можно добавить пароль на зоны — скажите, когда будете готовы.
